# Contributing to Entask

Thank you for your interest in Entask. This page explains what kinds of feedback are welcome and how to send them.

## What is welcome

- **Bug reports** — use the bug report template when one is available.
- **Feature proposals** — describe the problem to be solved, the users affected, and the workflow you have in mind. A proposed implementation is helpful, but the problem description matters more.
- **Documentation corrections** — wrong instructions, outdated screenshots, unclear wording, translation fixes. **Send them as an Issue, not as a Pull Request** — a one-line fix is still a code contribution (see below).
- **Deployment experience** — what worked, what did not, on which environment.

Please search existing Issues and Discussions before opening a new one.

## What is not accepted: code contributions

**Entask does not accept code contributions, Pull Requests, or patches at this time.** This is a deliberate policy, not a judgement about your work.

### Why

Entask is released under the GNU Affero General Public License version 3.0 (AGPL-3.0), and the maintainer intends to keep the option of offering separate commercial licence terms. That dual-licensing model requires the maintainer to hold, or control, the copyright in every part of the codebase. Accepting outside code would require a Contributor Licence Agreement and a legal entity able to receive those rights; neither exists today. Keeping all code authored by the maintainer keeps the licensing position unambiguous.

### What this means in practice

- A Pull Request may be closed without review of its code.
- **Do not use the "Commit suggestion" button** on a file — accepting it would create a code contribution, with the same problem as a merged Pull Request.
- If you have already written a patch, you are welcome to publish it in your own fork. AGPL-3.0 permits that. It cannot be merged here.
- Nothing above prevents you from using, studying, modifying, or redistributing Entask under AGPL-3.0. See the `LICENSE` file.

This policy may change in the future. If it does, this page will say so explicitly, and no contribution made before that change will be treated as accepted.

## Reporting bugs

Include the Entask version, how it was deployed, the operating environment, relevant configuration, steps to reproduce, expected behaviour, actual behaviour, and logs. Screenshots help only when they do not expose private information.

Do not include passwords, API tokens, personal information, customer data, or confidential business information in a public Issue. If you need to share something private, see `SECURITY.md` for the private channel.

## Reporting security issues

Do not open a public Issue for a suspected vulnerability. Follow `SECURITY.md`.

## Content you post

Issue descriptions, comments, diagnostic logs, screenshots, and discussion material that you post publicly remain yours. Because Entask does not accept contributions, the project makes no claim to them — but please do not post material you are not authorised to disclose, and do not post other people's code, images, fonts, or documentation without their licence and attribution information.

If you accidentally post confidential information, personal data, credentials, or unauthorised third-party material, contact [contact@zebrodev.com](mailto:contact@zebrodev.com) immediately with the affected URL or commit identifier, and do not repeat the sensitive content in a public channel. The maintainer may remove, restrict, or quarantine the affected material where reasonably practicable.

## AI-assisted reports and proposals

AI-assisted text is fine. AI-assisted *code* is not accepted, because it cannot be merged. For anything you post, you are responsible for its accuracy and for not disclosing confidential inputs.

## Questions

For public technical discussion, use GitHub Issues or Discussions when enabled. For private licensing, commercial, or authorisation matters, contact [contact@zebrodev.com](mailto:contact@zebrodev.com). For security vulnerabilities, follow `SECURITY.md` instead.
