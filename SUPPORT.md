# Support Policy

## Public Community Support

Use GitHub Issues for reproducible bugs and feature proposals. When GitHub Discussions is enabled, use it for questions, usage ideas, deployment experiences, and broader project discussions.

Before opening a new question, search existing Issues, Discussions, and documentation. Include the Entask version, deployment method, relevant environment details, and a clear description of the problem. Do not publish secrets, personal information, customer data, or confidential business information.

## Private Support

For deployment details that cannot be shared publicly, contact [support@zebrodev.com](mailto:support@zebrodev.com). For commercial licensing, integrations, white-label use, redistribution, custom development, or formal support discussions, contact [contact@zebrodev.com](mailto:contact@zebrodev.com).

## Support Scope

Community support is provided on a best-effort basis through public documentation and project discussions. It does not currently include guaranteed response times, production availability, incident response, data recovery, custom development, or a service-level agreement.

Commercial support, deployment assistance, maintenance arrangements, and custom development may be discussed separately as the project and support process mature. Any such service is subject to a separate written agreement.

## Before Asking for Help

Please check the documentation, confirm the installed version, reproduce the issue with the latest applicable version, review recent release notes, and collect relevant logs with secrets removed. A small reproducible example is often the fastest way to resolve a technical problem.
